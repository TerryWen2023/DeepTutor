# 温习 · 小学、初中与高中学习伙伴

温习是 DeepTutor 仓库中的独立 Windows 桌面应用，使用 React 与 Electron 构建。1.2.0 支持小学一年级至高中三年级，同一台电脑上的多个学生账号分别拥有学习档案、试卷、错题和 AI 连接设置。它提供知识点导览、原创离线练习、AI 文字辅导，以及 JPG、PNG、PDF 试卷归档和讲解。

这个桌面应用是 `desktop/wen` 下的新增产品入口，独立调用 AI 服务；它目前没有接入 DeepTutor 原有的 `TurnApplicationService`、WebSocket 或能力注册系统。原有 DeepTutor CLI、Web/API 与 Python SDK 的运行方式不受影响。

## 开始学习

1. 运行 Windows 安装程序，选择安装目录，完成后打开“温习”。
2. 为每位学生建立独立的用户名和密码，填写姓名 / 昵称及年级。密码至少 6 位；重新打开应用后需要登录。
3. 登录自己的学习空间，选择学科或先做离线练习。在“连接设置”配置该学生使用的 AI 服务，再进入学习对话。
4. 在“试卷档案”上传单元测验或统考试卷，查看原卷、请求讲解，按需要收进错题本。
5. 换学生使用时，点击左下角“退出 / 切换账号”。应用会先保存当前档案；进行中的回答或操作须先完成或停止。

升级后首次建号时，旧版学习记录和连接配置会复制到第一个账号，旧文件保留。其余新建账号从独立的空白档案开始。请选择应接收旧记录的学生先建号。

离线知识点、样例练习和已保存的学习记录无需 AI 账户。AI 回答需要网络、相应服务的账户权限与可用额度。

## 两种 AI 连接方式

### Codex 登录

在设置中选择 Codex，点击登录，在系统浏览器打开的官方登录页面完成账户登录，再回到温习检查状态。Windows 安装包会随附官方 Codex CLI，不需要另外安装 Node.js、Python 或 Codex CLI。

每个学生账号使用独立的 Codex 数据目录，与其他学生及其他 Codex 安装的登录分开。温习的学习账号密码和 OpenAI 官方账号密码是不同的凭据；官方登录在浏览器完成。自定义 Codex 模型可使用 `auto`，由 CLI 和账户可用配置决定；指定的模型必须对当前账户可用。

“测试连接”会请求模型实际回答，同时检查网络、模型权限和额度。应用自动读取 Windows 系统代理设置，并在有明确代理环境变量时优先使用环境变量；系统代理服务需要正常运行。已登录但无法回答时，可先到连接设置重新测试，查看具体错误。

### DeepSeek API Key

在设置中选择 DeepSeek，填写从 DeepSeek 官方开放平台取得的 API Key，保存后测试连接。API Key 是 API 访问凭据，不是 DeepSeek 网站的登录密码。请求发送到 `https://api.deepseek.com`；模型名称应使用当前账户可用的模型，可通过连接检查确认。

DeepSeek API 的账户余额和用量由其官方平台管理。温习不会为你充值，也不包含赠送的 API 额度。

## 内置学习内容

| 年级 | 学科 |
| --- | --- |
| 小学一至二年级 | 数学、语文、科学 |
| 小学三至六年级 | 数学、语文、英语、科学 |
| 初中七年级 | 数学、语文、英语、历史、地理、生物 |
| 初中八年级 | 上述初中学科，加物理 |
| 初中九年级 | 上述初中学科，加化学 |
| 高一、高二、高三 | 语文、数学、英语、物理、化学、生物、历史、地理、思想政治 |

当前内置 **70 组年级与学科组合、280 张知识点导览卡、237 道原创离线样例题**。小学与初中每组含 4 张导览卡与 3 道带解析的练习；高中新增 27 组，每组含 4 张导览卡与 4 道练习。地理、生物等学科在九年级提供复习导览，实际开课和结课年级以学校安排为准。

高中以中国大陆通用学习主题组织，高一侧重基础、高二侧重拓展、高三侧重综合复习。九科是当前产品的覆盖范围，并非高中全部课程。学科设置参考[教育部普通高中课程方案和课程标准修订通知](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)；各地教材、必修与选择性必修的安排和选科进度不同，内置年级分组是学习建议，不是统一教学进度表。

书桌上的每个知识点可直接进入讲解或对应的离线练习；练习页可切换“本科全部样例”和指定知识点。书桌依据当前年级、学科及各题最近一次作答，优先推荐答错的知识点，再推荐尚未完成的练习。显示“样例已答对”不代表掌握整个知识点。已标记掌握的错题若再次答错，会重新进入待温习列表并更新学生作答；一次答对不会自动标记掌握。

这些内容用于基础复习与产品体验，**不是完整课程或完整题库，也没有宣称与某个教材版本同步**。AI 可以围绕选定年级、学科和知识点继续讲解、出题与解析；AI 生成的内容需结合教材和老师指导核对。内置题目是自行编写的短题，不含复制的教材章节或配套题库。

支持文字输入、Markdown / 数学公式显示和试卷图片识别；没有提供联网检索或语音课堂。

## 试卷归档与错题讲解

在“试卷档案”填写名称、学科、年级、考试日期、单元测验 / 统考类型和可选单元名称，然后选择文件。支持多选 JPG、PNG、PDF；单个文件最多 30 MB，一次合计最多 100 MB、30 页。文件按文件名顺序编号，原始文件保存在当前学生的档案中，断开 AI 连接时仍可上传与查看。

试卷图片讲解当前使用 **Codex**；DeepSeek 可用于文字辅导，但不能直接分析试卷图片。选择每次 1 至 6 页，例如 `1-3,5`，填写错题题号、学生作答或讲解要求，再开始讲解。较长试卷可分批处理；历次成功讲解会保留，可通过“查看历次讲解”切换。失败或停止时保留原卷及已有讲解。

没有学生答案或明确批改痕迹时，不能仅凭试卷判定哪些题答错。请补充学生作答，或明确指定需要讲解的题号。确认后点击“收进错题本”，会保存讲解、试卷来源和对应页码；从错题本可返回原试卷档案。AI 的文字识别和讲解均可能有误，请结合原卷、教材和教师批改核对。

## 本机数据与隐私

学习档案保存在当前 Windows 用户的应用数据目录，通常为 `%APPDATA%\温习`。学习账号用于在应用内分开档案，密码以加盐哈希保存；**本机密码不等于磁盘加密**，拥有相应 Windows 文件权限的人仍可读取本机学习文件。

可以从“学习足迹”或应用菜单导出当前账号的 JSON 记录，包括学习记录、试卷元数据和已保存讲解。JSON 不含试卷原始图片 / PDF、API Key 或 Codex 登录凭据。完整备份应在退出应用后另行保存 `accounts.json` 和 `profiles/` 目录；目录中含 AI 登录凭据，应按敏感资料保管。不要只依赖 JSON 来备份原卷。

主要文件包括：

- `accounts.json`：本机账号索引、密码哈希和旧档案迁移记录。
- `profiles/<账号编号>/study.json`：该学生的学习档案、对话、错题和活动记录。
- `profiles/<账号编号>/settings.json`：该学生的服务选择和模型设置。
- `profiles/<账号编号>/deepseek-key.bin`：通过 Electron `safeStorage` 使用 Windows 用户级安全存储加密的 API Key。
- `profiles/<账号编号>/codex/`：官方 Codex CLI 管理的独立登录状态及运行数据。
- `profiles/<账号编号>/exams/`：试卷原件、转换后的页面图片、试卷信息和讲解。

AI 辅导会将本次请求包含的对话、年级、学科和知识点发送给所选服务；试卷讲解还会发送所选页面和补充作答。可先遮盖试卷上不必要的姓名、学校和其他个人信息。学习记录没有自动云同步；卸载默认保留本机数据，重新安装后可继续使用。导出备份目前用于查看与保管，没有提供一键导入界面。

## 开发与验证

在 Windows x64 环境准备 Node.js 22.12 或更新的兼容版本，然后在本目录执行：

```powershell
cd E:\DeepTutor\desktop\wen
npm install
npm test
npm run build
npm run desktop
```

`npm run desktop` 打开已经构建的本地页面。开发时如需前端热更新，可在两个终端分别运行：

```powershell
# 终端一：前端开发服务
npm run dev
```

```powershell
# 终端二：Electron 桌面窗口
$env:WEN_DEV_URL = 'http://127.0.0.1:5173'
npm run desktop
```

直接在普通浏览器打开 Vite 页面仅适合离线界面预览，学生账号、试卷导入、系统登录、凭据安全存储和桌面导出功能需要 Electron。

单元测试覆盖输入校验、账户接口、凭据保护与服务错误处理，以及年级学科覆盖、题目与选项有效性、编号唯一性、数学答案、物理计算和数据复制隔离。测试使用隔离目录与模拟服务，不表示已经替用户登录或验证真实账户额度。

## 构建 Windows 安装包

```powershell
npm run dist:win
```

构建流程先打包前端，再复制 npm 发布的官方 Windows x64 Codex CLI，最后使用 electron-builder 生成 NSIS 安装程序。预期输出路径为：

```text
release/Wenxi-Setup-1.2.0-x64.exe
```

只生成可直接运行的应用目录可使用 `npm run pack:win`。最终安装包是否成功生成、通过哪些本机检查，以实际构建日志和交付说明为准；本说明不将构建脚本存在视为安装验证成功。

发布者尚未配置代码签名证书时，安装包不会具备可信发布者签名，Windows 可能显示发布者提示。正式分发前应配置证书，并在目标 Windows 版本和全新用户账户上验证安装、卸载、登录和联网回答。

## 主要源码

- `src/curriculum.js`：原创知识点和离线练习；提供 `GRADES`、`getSubjects`、`getTopics`、`getPractice`。
- `src/high-school-curriculum.js`：高中九科的原创导览与练习样例。
- `shared/education.js`：界面、账号、试卷与 AI 请求共用的年级和学科规则。
- `src/study-flow.js`：知识点最近作答状态、学习建议与错题回访规则。
- `src/`：学习界面、状态管理和样式。
- `electron/main.cjs`：窗口、菜单与桌面 IPC。
- `electron/backend.cjs`：AI 服务连接、本机学习数据与凭据存储。
- `electron/accounts.cjs`：独立学生账号、密码校验、会话隔离与旧记录迁移。
- `electron/exams.cjs`：试卷原件归档、PDF 页面转换及讲解留存。
- `electron/preload.cjs`：界面可用的受控桌面 API。
- `scripts/prepare-codex.cjs`：准备随安装包分发的官方 Codex CLI。
- `assets/icon.png`、`assets/icon.ico`：应用图标与 Windows 图标。
- `tests/`：独立单元测试。
